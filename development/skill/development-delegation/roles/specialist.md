# Optional Specialist Role

Instantiate only for a concrete capability gap (for example graph discovery, security,
performance or migration analysis), not as a permanent team member. Assignment names
the specialty, question, role module/additional domain contract, capability need,
authorized binding, scope, output/evidence, budget and stop condition. Default read-only;
any mutation needs explicit bounded authority and isolation. Specialists do not own
scope expansion or substitute for required independent review without its independence
and capability contract. Graph specialists preserve references/discovery.md and the
existing codebase-memory-scout identity when explicitly selected.

Select a named specialty from routing/capabilities.yaml only when its condition is
met. Its evidence and limits are part of the assignment, not general permission.
Architecture choices stay with the authorized decision owner; debugger experiments,
benchmarks and migration dry runs need explicit side-effect/resource bounds. A
security auditor is not automatically an independent reviewer. An integrator loads
modules/integration.md and validates the combined state.
