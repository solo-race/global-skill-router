# Global Skill 结构构建

## 目的

为了加强对Codex开发的环境助力，故而建立此项目，通过简介成熟的SKILL结构，来为本地Codex运行环境提供一个完整的SKILL体系。

## 当前状态

项目刚刚开始，还未确定架构，但已有一成熟案例列入`references`，故而在开始后，应当先对`references`中列出的SKILL体系进行分析，拆解其结构，然后依照其成熟架构，在`development/skill`文件夹中对其SKILL架构进行重建。

## 开发项目背景

当前本机开发场景有：

1. Windows原生项目，如SQL数据库管理，ACCESS前端管理、ACCESS/EXCEL VBA编写；
2. Windows系统下的安卓应用开发；
3. WSL中的原生筛选项目，使用Python脚本。
